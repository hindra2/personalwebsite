## Writing a post

Add a Markdown file to `src/content/blog/`. The filename becomes the URL, so `my-post.md` lives at `/blog/my-post`.

- Lists, **bold**, _italics_ and [links](https://github.com/hindra2) all work
- So do tables and ~~strikethrough~~
