## About

Akar is an open-source flashcard platform that uses spaced repetition to help you remember what you study. We're big fans of studying with flashcards, but the go-to app, Anki, has an outdated interface that makes it hard to pick up, especially for people who aren't technical. So we built Akar with a cleaner, friendlier interface and a Pomodoro timer built in, so studying and staying focused happen in the same place.

## Features

- Reviews scheduled with a spaced-repetition algorithm, so cards come back right before you'd forget them
- A built-in Pomodoro timer to keep study sessions focused
- A statistics dashboard to track your learning progress
